# Handwriting font sources

The fonts below were added from [Google Fonts](https://fonts.google.com) and
renamed to this directory's scheme: `MixHand*` write both alphabets,
`LatinHand*` only Latin. Each one's licence is kept beside this file under
the font's new name. All are free to use, modify and redistribute; the SIL
Open Font License asks only that the fonts are not sold on their own and
that a modified font does not keep its reserved name.

Uzbek line in each and keeping those that read as a person's ordinary pen
writing; calligraphic, brush and display faces were left out. Caveat, which
was also chosen, is already here as `MixHand03`.
